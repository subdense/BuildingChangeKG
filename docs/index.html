Building Changec back to ToC or Class ToC

IRI: http://www.semanticweb.org/bbucher/ontologies/2025/6/UrbanDensificationKG#BuildingChange

This is some change of one or more buildings -e.g. creation, demolition, change of use-. These can be changes of real world building entities, or changes of building data, or both. One same class is used to represent these different things because distinguishing them would lead to verbose and complexe models. A BuildingChange can be associated with geodata that represent it, this is stored as a property called buildingChangeFeatures which is a query to identify this data.

Change Itemc back to ToC or Class ToC

IRI: http://www.semanticweb.org/bbucher/ontologies/2025/6/UrbanDensificationKG#ChangeItem

A change item is a specific case of building change in reality, that can be of different sizes (e.g. destruction of a building, or development of a residential neighbour over several years), that is observed through data (different data like aerial imagery before and after, change features if they exist, etc.) and described through narratives (acquired on the Web or collected during experts sessions).
